# ssh-key-provision-codex-cli-github

Codex skill for configuring SSH public-key login from Windows/Codex Desktop to Linux hosts and installing Codex CLI from bundled offline packages.

Install with Codex skill installer from this repository path:

```powershell
python install-skill-from-github.py --repo <owner>/<repo> --path skills/ssh-key-provision
```

The skill includes offline Codex CLI packages for Linux x64 and ARM64/aarch64.
